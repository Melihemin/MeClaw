# MeClaw Web Arayüzü — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MeClaw'u Telegram botundan, Ollama/OpenAI ve model seçimi yapılabilen, yalnızca 127.0.0.1'de çalışan bir FastAPI + sade HTML/JS web arayüzüne taşımak.

**Architecture:** `meclaw/` paketi provider'ları (Ollama, OpenAI), araç kaydını, provider'dan bağımsız araç döngüsünü (agent) ve SQLite saklamayı barındırır. `server.py` bunları `create_app(...)` ile FastAPI'ye bağlar ve sohbet yanıtını SSE ile akıtır. `static/` build adımı olmayan arayüzü içerir.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, ollama 0.6.x, openai (AsyncOpenAI), sqlite3, pytest + fastapi TestClient (httpx).

**Spec:** `docs/superpowers/specs/2026-10-25-web-ui-design.md`

## Global Constraints

- Sunucu yalnızca `host="127.0.0.1", port=8000` ile başlar.
- Klasör dışı erişimde dönen mesaj tam olarak: `Path is outside the workspace.`
- Bilinmeyen araç: `Unknown tool: <ad>`; hatalı argüman: `Invalid arguments for <ad>: <hata>` ile başlar.
- Araç döngüsü en fazla 5 tur.
- Sohbet başlığı ilk kullanıcı mesajının ilk 40 karakteri (`strip()` sonrası).
- Ortam değişkenleri: `OLLAMA_HOST` (varsayılan `http://localhost:11434`), `OPENAI_API_KEY` (boşsa yok sayılır), `MECLAW_DB_PATH` (varsayılan `<proje kökü>/data/meclaw.db`).
- `OPENAI_API_KEY` hiçbir yanıta, SSE olayına veya log satırına yazılmaz.
- SSE ve JSON çıktılarında `ensure_ascii=False`; Türkçe karakterler bozulmadan geçer.
- Testler ağa çıkmaz; `tools/finder/testdir` içeriği testlerde değiştirilmez (`tmp_path` kullanılır).
- Async testler için ek eklenti yok: `asyncio.run(...)` kullanılır.
- Spec'ten bilinçli sapma: `ChatEvent.type` yalnızca `"text" | "tool_calls"`; turun bitişini iterator'ın bitmesi bildirir (`done` gereksiz).

## Ortak mesaj biçimi (tüm görevler bunu kullanır)

```python
{"role": "user", "content": str}
{"role": "assistant", "content": str, "tool_calls": [{"id": str, "name": str, "arguments": dict}]}  # tool_calls opsiyonel
{"role": "tool", "content": str, "tool_call_id": str, "name": str}
```

Sistem mesajı saklanmaz; agent her çağrıda başa ekler.

## Review Focus

1. Ollama sohbet ortasında kapanır veya API anahtarı geçersizdir → kullanıcı bir hata mesajı görür, o ana kadarki mesajlar kaydedilir, akış `done` ile kapanır, sunucu çalışmaya devam eder. (Task 7: `test_chat_provider_error_mid_stream`)
2. Kullanıcı Ollama'da araç desteklemeyen bir model seçer (Ollama `ResponseError`: "does not support tools") → sohbet araçsız olarak yine çalışır. (Task 4: `test_retries_without_tools_when_model_lacks_support`)
3. Türkçe karakterler (`ğüşıöçİ`) mesajlarda, başlıkta ve SSE'de bozulmadan gidip gelir. (Task 6: `test_turkish_roundtrip`, Task 7: `test_chat_streams_turkish`)
4. Silinmiş/bilinmeyen sohbete veya boş mesajla istek → akış başlamadan 404 / 400, hiçbir şey kaydedilmez. (Task 7: `test_chat_unknown_conversation_404`, `test_chat_empty_message_400`)
5. Model listesi alınamaz (Ollama kapalı, anahtar geçersiz) → `/api/models` 500 değil 503 ve nedeni döner; `/api/providers` her durumda 200. (Task 7: `test_models_provider_failure_503`, `test_providers_never_500`)
